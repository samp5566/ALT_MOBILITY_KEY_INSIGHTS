# ALT_MOBILITY_KEY_INSIGHTS
This is an assignment based analysis of Alt Mobility, Integrated EV Asset Management Services. 

## Overview
Alt Mobility is EV leasing and offering management services to B2B fleets, individual drivers and corporate employees. This analysis provides actionable insights to resolve orders fulfillments, streamline payments, and combat churn by understanding customer behavior, ultimately maximizing overall performance.

## Data Cleaning and Preparation
The initial phase included data cleaning in Microsoft Excel followed by extraction in MySQL database to facilitate efficient querying and analysis. 

## Data Analysis by SQL 
Executed SQL queries for detailed analysis to address the following challenges
1)	Orders performance
2)	Revenue trend
3)	Customer segmentation
4)	Payment processing issues
5)	Overview of order and payment details

## Customer Retention with Power BI
The final stage involved a focused analysis of customer retention. A dynamic dashboard was created in Power BI by directly connecting to the MySQL database. This dashboard was designed to track customer churn patterns.
